# resin-privacy

The public pages for the Epoxy Resin Calculator Android app, served by GitHub Pages:

| Page | Address | Source |
| --- | --- | --- |
| Android privacy policy | <https://elmehdimotaqi-ui.github.io/resin-privacy/android/> | `android/index.md` |
| Support | <https://elmehdimotaqi-ui.github.io/resin-privacy/support/> | `support.md` |
| Home | <https://elmehdimotaqi-ui.github.io/resin-privacy/> | `index.md` |

These addresses are what Google Play and the app have on file, so **they must not change**: renaming this repository
would break them.

`android/index.md` comes from `docs/privacy-policy.md` in the app repository (the markdown block under "Page
content"). Change both together and move the effective date whenever the text changes: the policy promises the current
version is at that address.
